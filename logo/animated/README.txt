TLF Studio — monogramme animé (6 variantes × clair/sombre)

Chaque SVG est autonome (CSS intégré, sans JavaScript), s'anime une fois au chargement
et respecte prefers-reduced-motion. Suffixe -light : encre #111111 sur fond clair ;
-dark : encre blanche sur fond sombre. Accent : #E8562A.

Utilisation : <img src="tlf-1-assemblage-light.svg" alt="TLF Studio"> ou inline dans le HTML.
Pour rejouer l'animation, réinsérer l'élément dans le DOM (cloneNode + replaceChild).

Emplacements prévus :
1  assemblage  → hero de l'accueil, intro vidéo, favicon animé (version inline)
2  trace       → page À propos, kit média / presse
3  glitch      → cartes projets verrouillées (au survol), page 404, teasers
4  balayage    → écran de chargement du site, chargement du dashboard admin
5  chute       → branche Jeux (page projet jeu), splash screen des jeux
6  impulsion   → notifications (toasts), bots Discord, animation de révélation
